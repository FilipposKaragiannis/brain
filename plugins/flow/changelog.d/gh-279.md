bump: minor

- The pr step opens the pull request through the new `scripts/pr-publish.sh open <reports> <base>
  <branch> <title> [--draft]`, never a `gh pr create` of its own. The script reads the body the
  pr-creator writes to `<reports>/pr-body.md`, swaps in the Verification section whole and
  attaches each image and video evidence file with `--attach`, so each one shows inline in the
  pull request.
- The Verification section lists each image and video under `evidence/` under an **Evidence**
  title, each reference alone in its paragraph so a video plays, before the text excerpts. A
  live proof of one says it is shown below. The references count against the excerpt budget at
  the length of an asset URL, and a link is never followed. An image or video whose file name
  holds a line break or another control character is left out of the section and the upload, so
  its name cannot add a line, such as a closing keyword or a heading, to the body.
- A file that does not upload fails the pr step: the pull request is still made or updated with
  the new Verification section, and the step names each file not attached, the one gh stopped at
  and every later one. An empty file, an image over 10 MiB or a video over 100 MiB is left out of
  the upload and named, so it does not hold back the others. `pr-publish.sh open` looks up the
  open pull request on the branch first, so the retry updates that pull request.
- More than 50 images and videos go up in batches of 50, as gh takes no more in one call. Each
  batch after the first is a `gh pr edit --attach` with no body flag, so the references the first
  call left local become asset URLs too. A failed batch stops the rest, and the step names each of
  its files and every later one.
- After a pass verify and a push, the comments step runs `pr-publish.sh refresh <reports> <branch>`.
  It replaces the open pull request's Verification section whole, its old asset URLs with it,
  attaches the new images and videos and keeps every line outside the section, an owner's edit
  to the Summary included. It creates no pull request, and it refuses a report made at another
  commit than HEAD.

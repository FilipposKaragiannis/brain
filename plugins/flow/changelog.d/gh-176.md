bump: minor

- Every flow read of flow state now comes from the flow record (gh#176, ADR 0004). A script reads
  an item with `item_read` and a list with `items_join` or `items_listed` (`lib/state.sh`), which
  join the record onto the adapter's item as `state` and stamp `state_from`; `scripts/state.sh`
  gains `read`, `join` and `list runs|gates [<item>]`. `state_get` in `lib/flow.sh` refuses an
  item with no `state_from`, and the new `state_list` reads `touches` and `changes` the same way.
  `board.sh --json` keeps `state` and adds `state_from`, so the console is unchanged.
- An item with no record yet reads the tracker's state while `tracker_state` is `labels` (the
  default) and an empty state under `none`. Under `labels`, its run and gate files still list as
  its rows, so a run or gate from before the records still shows.
- `gate.sh list`, the board, the health job, `next.sh` and `hold.sh` list runs and gates from the
  records. `filter-ready.sh` joins each item's record before it filters, and holds an item for
  `ready.needs` only while its state has no step. `steward.sh pool` takes its step column from
  the record's run, else its step.
- `next.sh` says `steward.sh stop <item>` for a run in flight, no longer to delete the run file,
  and keeps its scratch files in `<flow home>/tmp`. The pr skill and the pr-creator read
  `state.base` with `state.sh get <item> base`, the plan skill reads its item with
  `state.sh read`, and the comments skill reads the item's `pr` with `state.sh get <item> pr`.
- `.flow/run-unattended.sh` changed, so `flow:init` asks to be run again.
- `tracker_state: none` still lacks three things: `answers` finds a gate by the tracker's label,
  the tracker's labels and cards do not follow the record, and another machine's claim is not
  shared. `plugins/flow/tests/run.sh` runs with the mirror on; the pass with it off runs on
  demand, `FLOW_TRACKER_STATE=none plugins/flow/tests/run.sh`, and skips the checks that need
  the mirror, naming what each waits on. CI and `tools/test.sh` do not run it.

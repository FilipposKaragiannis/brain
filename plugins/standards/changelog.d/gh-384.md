bump: minor

- Init now migrates an existing `.standards/config.json` before anything reads it: it runs the
  plugin's ordered step list (`skills/init/migrations.json`), which looks only at the file, so a
  second run changes nothing. Keys keep their order, the file its indent unit, its final newline
  and its non-ASCII text.
- The first step writes `comments.doc_inside: ["interface", "enum"]`, the default the hook already
  assumed, into each language with `comments.doc` and no `doc_inside`. A language with
  `"doc_inside": []` keeps it. Init's note that the key is missing is gone, and on an existing
  config the skill now says init wrote the default.
- When a step changes the file, init sets `version` to the plugin version, saves the old file to
  `.standards/migrations/config.json.<version found>.bak` and appends the changes to
  `.standards/migrations/report.txt`, one line each: old key, new key, value and reason, split by
  tabs. The folder ignores itself, so a committed `.standards/` shows only the config's diff. The
  first backup is named after the version that created the file, which may be older than the
  plugin that last ran init; from the second migration on, the name gives the version it migrated
  from. A release with no step for the file leaves it alone.
- This release retires no standards key, so there is no old key to read: the hook reads a missing
  `doc_inside` as the default it read before, which the first step now writes.
- The first session start after a migrating init prints its changes once, under a note for the
  owner. `report.txt` keeps the record. The glue for both, `config_migration.sh`, is shared with
  the flow plugin and lands in `.standards/hooks/` with the other hook copies.
- `init --check` lists each pending change as drift and writes nothing. A config that is not a
  JSON object is left as it is, with a note. So is one that changes while init migrates it, with
  no backup or report line and a note to run init again; the check runs just before the replace,
  so a write in that last moment can still be lost.
